Progress note - 15 November 2026

The checkpoint 3 implementation is complete. Authentication and file mutations
use signed CSRF tokens and origin checks. The application includes a nonce-based
Content Security Policy, validated uploads, owner-scoped file operations,
parameterized database queries, generic errors and structured security logs.
Filename search, storage quotas and a public health endpoint are also available.

Development checks covered forged requests, XSS and SQL payloads, cross-user
file access, ciphertext tampering and session revocation. The draft report is
available at output/pdf/checkpoint3-report-draft.pdf and covers Introduction,
Implementation, Security Analysis and Conclusion. Remaining work includes
checking the report against the course's complete formatting instructions and
addressing the documented operational and development-tool limitations.
